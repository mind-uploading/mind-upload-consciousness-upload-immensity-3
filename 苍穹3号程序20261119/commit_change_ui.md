# 修改记录：记忆包导入/导出界面化

- 版本目录：`苍穹3号程序20261118`
- 日期：2026-11-18
- 范围：把"记忆同步/保存"从命令行逐项输入改为界面操作，支持一键导入/一键导出与逐文件模式
- 数据文件：未改动 `意识数据/` 下任何已有文件（测试全部写在临时目录并已清理）

---

## 一、目标

1. 启动时不再连续询问 8~9 次版本号，改为一个选包界面，直接展示磁盘上已有的版本。
2. 导出时不再连续询问 8 次版本号，改为一个导出界面。
3. 一键导入/导出：只给一个"名字 + 数字版本号"，9 类文件路径自动拼出。
4. 保留逐文件模式：在同一张文件明细表里单独指定某几行。
5. 确认键必须有效：输入未完成或非法时，"确认"按钮不可用；点亮后仍需二次确认。
6. 导入/导出页签不能自由切换（导入只在启动时、导出只在运行中）。
7. 兼容旧包：旧文件名（如 `研究者_v1`、`100`）照常列出、照常一键导入。

### 3.2 包名规则

`包名 = 名字（字符） + 版本号（数字）`

- `名字` 留空 → 自动用 `空白研究者`
- `版本号` 必须是 ASCII 数字，否则返回错误
- `名字` 不能包含 `\ / : * ? " < > |`
- `拆分包名`、`建议版本号`（同名字下已有最大号 +1）用于导出界面预填

### 3.3 对外函数（全部非交互）

| 函数 | 作用 |
|---|---|
| `列出记忆包()` | 扫描 9 个目录，返回 `{包名: {路径, 最后修改时间}}` |
| `包内文件(包名, 覆盖路径)` | 导入用：逐类路径、是否存在、文件里的条数 |
| `导出预览(包名, 覆盖路径)` | 导出用：逐类目标路径、内存条数、新建/覆盖/跳过 |
| `导入记忆包(包名, 覆盖路径, 跳过坏行, 提交)` | 读取一个包；`提交=True` 且无坏行时才写入 `公共状态` |
| `导出记忆包(包名, 覆盖路径)` | 把内存 9 类写成包；两阶段写出 |
| `规范化包名(名字, 版本号)` | 校验并拼出包名 |
| `建议版本号(名字)`、`拆分包名(包名)` | 导出预填用 |

### 3.4 数值类型修正

- 行为习惯的 `v`、自传体记忆的 `vsum`：按 float 读（运行时本来就是小数，如 `0.0`、`3.5`、`-4.5`），修复"程序自己导出的文件自己读不回来"。
- 情绪强度：按数字读，整数值存为 int，保持界面显示为 `5` 而不是 `5.0`。
- 状态转移的概率/次数、词典与词转移的权重：概率与权重 float，次数 int。
- 写出时整数浮点写成整数（`5.0` → `5`），非整数用 `repr()`（最短且可精确回读），保证导入导出不丢精度。

### 3.5 坏行策略

- 解析时逐行记录坏行（行号、原文、原因），**不静默丢弃**。
- `提交=False` 时只做试读；有坏行则返回错误，由界面询问"是否跳过坏行"。
- 选择跳过后才真正提交，报告里显示"已跳过 N 行"。
- 缺失文件按空表导入，并在界面标出"缺失"。

### 3.6 写出方式

- 先全部写入 `*.tmp`，全部成功后再逐个 `os.replace` 替换；中途异常删除临时文件。
- 避免出现"半新半旧"的记忆包。
- 导出时若 ART 模型未加载，跳过 ART 并在报告/界面提示。

## 四、全局神经工作空间.py

### 4.1 记忆包窗口 `记忆包窗口`

- 一个窗口两种模式：`导入` / `导出`，由打开入口决定，窗口内不可切换（点另一个标签会提示原因）。
- 顶部：模式标签 + 说明。
- 查询行：`名字`、`版本号` 输入框（可手动输入筛选）+ `查找` 按钮；导入模式下逐字筛选已有版本。
- 包名行：`记忆包` 输入框；导入模式可直接键入完整包名，导出模式只读、由名字+版本号自动生成并显示"将导出为：xxx（N 条记录）"。
- 已有版本表：包名 + 9 类条数 + 修改时间；缺失显示 `—`，双击选中。
- 文件明细表：9 行（类型、文件路径、条数、状态）；导入显示"存在/缺失（按空表）/缺失（ART置空）"，导出显示"新建/覆盖/跳过"。
- 按钮：`单独指定所选行…`（逐文件模式）、`恢复自动`、`确认导入/确认导出`、`退出/关闭`。
- 确认键：默认 `disabled`，只有输入合法且（导入时）至少找到 1 个文件才点亮；点亮后仍弹二次确认。
- 导入成功即关闭窗口，主程序继续加载模型；导入模式关闭时若尚未导入会提示"程序将退出"。

### 4.2 主界面改动

- 原"保存当前记忆 / 确认保存当前记忆"两个勾选框，替换为：
  - `每回合自动保存到当前记忆包` 勾选框
  - `记忆包…（导出）` 按钮（打开导出窗口）
- 导出窗口为模态（`grab_set` + `wait_window`），打开期间主循环暂停，保证导出的是同一回合边界的状态。

### 4.3 `打开记忆包窗口(模式)`

- 启动时调用 `打开记忆包窗口("导入")`，阻塞到窗口关闭。
- 运行中由按钮调用 `打开记忆包窗口("导出")`。
- 已存在窗口时只置顶，不重复创建。

## 五、主程序.py

### 5.1 启动顺序

原来：

```
设置（命令行） → 同步记忆（8 次输入） → 加载知觉模型（第 9 次输入） → 初始化摄像头 → 初始化界面 → 主循环
```

现在：

```
设置（命令行，未改动） → 初始化界面 → 打开记忆包窗口("导入") → 加载知觉模型(当前记忆包) → 初始化摄像头 → 主循环
```

- 未导入直接关闭窗口：打印"未导入记忆包，程序退出"，销毁窗口退出。
- ART 不再单独询问版本号。

### 5.2 回合末

原来：`if mode != "0": 保存记忆()`（8 次输入）

现在：

```python
if mode != "0" and varcb自动保存.get() == 1 and 当前记忆包:
    导出记忆包(当前记忆包)
```

- 未勾选则完全不写盘、不询问。
- 勾选后每回合末静默写回当前包（导出窗口里会提示这一行为）。

## 八、交互规则汇总

1. 导入只在启动时、导出只在运行中；窗口内的两个标签不能直接切换。
2. 确认按钮默认不可用；版本号为空、非数字、名字含非法字符、导入时找不到文件，都会保持不可用并显示原因。
3. 确认按钮点亮后仍需在二次确认框点"是"才执行。
4. 导出默认名字 = 当前包名去掉尾部数字（没有则"空白研究者"），版本号自动取同名字下最大值 +1，避免误覆盖；如确要覆盖，二次确认里会提示。
5. 导入时若自传体记忆不足 5 条、行为空间为空，会在确认框里给出警告。

## 十一、已知限制 / 后续可做

1. 启动时的"设置"（模式、阈值、睡眠时间、图像来源）仍是命令行，本次未改；可再做设置窗口。
2. 勾选"每回合自动保存"后，每回合整包重写 9 个文件；自传体记忆积累变大后会变慢，可改为只写有变化的类型或改手动导出。

4. 旧包的命名不是"名字+数字"，导出界面对其预填可能得到类似 `研究者_v2` 的新名字，属预期行为。
